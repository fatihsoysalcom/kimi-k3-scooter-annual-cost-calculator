# Kimi K3 Scooter Annual Cost Calculator

This Python script calculates the estimated annual operating cost of a Kimi K3 electric scooter. It takes into account electricity consumption, charging losses, maintenance, insurance, and minor spare parts based on user-provided annual travel distance. The script demonstrates how various cost components contribute to the total ownership cost.

## Language

`python`

## How to Run

1. Save the code as `kimi_k3_cost.py`.
2. Run from your terminal: `python kimi_k3_cost.py`
3. Enter your estimated annual travel distance in kilometers when prompted.
